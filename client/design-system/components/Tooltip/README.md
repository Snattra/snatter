# Tooltip

A short label on `floating` that names an icon-only control. It appears after a 120ms rest on hover or focus, sliding 4px in from the anchor, and leaves faster than it came.

**Provide** `label`, `side` (`top`, `right` or `bottom`), and one focusable child. The child is described by the tooltip.

- Do use it on RailServers and IconButtons.
- Don't put interactive content or more than one line in it.
