# Callout

A tinted block of explanation inside a card or pane: `accent-soft` for information, `warning-soft` for caution.

**Provide** `title` and `children` (one or two sentences, in `text`). An example is the first-run notice: "Set up your server. This server has no accounts yet…".

- Don't add a coloured left border; the tint is the signal.
