# Icon

A filled glyph on a 24px grid, drawn at `icon-size` in the current text colour. Includes the app's own `hash`, `speaker`, `members`, `chevron-left` and `chevron-right`, plus `plus`, `close`, `send`, `arrow-right`, `arrow-up`, `person-add`, `settings`, `chevron-down`, `check` and `ban`.

**Provide** `name`, and `size` only when the context needs more than 18px (the add-server button uses 24). Icons are always decorative: name the control that holds them.
