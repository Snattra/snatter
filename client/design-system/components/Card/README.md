# Card

A `panel` surface for a single task on the bare ground, such as signing in or setting up a server, with a 1px sheen along its top edge (`gradient-edge`). It rises in when it mounts.

**Provide** `title` (the community name, in `text-title`), an optional `description`, and `children` stacked 12px apart: Tabs, Fields, a block primary Button. Centre it in a `Backdrop`, which lays the `gradient-backdrop` and `gradient-backdrop-far` glows over `bg`.

- Do keep a card to one task, 400px wide at most.
