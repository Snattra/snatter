# Tabs

A segmented choice between two to four views of one surface, such as Sign in and Create account. The selected tab's `gradient-accent` fill slides to the new tab on `ease-spring`.

**Provide** `tabs` (`{ id, label }`), `value`, `onChange`, and `label` for the tab list. The arrow keys move the choice.

- Don't use Tabs for navigation between channels or pages.
